# 🧊 AI-Powered Smart Cold Supply Chain Monitoring System

An AI-powered IoT solution for real-time monitoring of temperature-sensitive goods such as vaccines, medicines, dairy products, and food throughout the cold supply chain.

## 🚀 Features

- Real-time temperature & humidity monitoring
- AI-based anomaly detection
- Live dashboard and analytics
- Alert generation for threshold violations
- Historical data visualization
- Scalable IoT architecture

## 🏗️ System Architecture

```text
Sensors (DHT/IoT)
      │
      ▼
 ESP32 / Microcontroller
      │
      ▼
 Cloud / Backend / Thinkspeak 
      │
      ▼
 AI / ML Prediction Engine
      │
      ▼
 Dashboard & Alerts
```

## 🛠️ Tech Stack

- Python
- Flask
- HTML, CSS
- Flutter
- Pandas, NumPy, Scikit-learn
- IoT Sensors (ESP32/DHT)
- SQLite/Firebase (as applicable)
- Thinkspeak (Stroing sensor data in cloud and reteriving it to dashboard)

```

## ⚙️ Installation

```bash
git clone https://github.com/tanishqkolhatkar93/AIOT_based_Cold_Supply_Chain_Monitoiring.git
cd AIOT_based_Cold_Supply_Chain_Monitoiring
pip install -r requirements.txt
python app.py
```
