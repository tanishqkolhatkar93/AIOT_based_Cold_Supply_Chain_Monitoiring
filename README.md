# 🧊 AI-Powered Smart Cold Supply Chain Monitoring System

An AI-powered IoT solution for real-time monitoring of temperature-sensitive goods such as vaccines, medicines, dairy products, and food throughout the cold supply chain.

## 🚀 Features

- Real-time temperature & humidity monitoring
- AI-based anomaly detection
- Live dashboard and analytics
- Alert generation for threshold violations
- Historical data visualization
- Scalable IoT architecture

## 🏗️ System Architecture

```text
Sensors (DHT/IoT)
      │
      ▼
 ESP32 / Microcontroller
      │
      ▼
 Cloud / Backend
      │
      ▼
 AI / ML Prediction Engine
      │
      ▼
 Dashboard & Alerts
```
